# 🎯 Let's Play! - Dart Game

연말 파티용 다트 게임

## Play Now
👉 **https://happyrym.github.io/letsplay/**

## How to Play

1. **다트를 잡고 위로 스와이프**해서 던지기
2. **10초** 안에 **3개**의 다트를 던지세요
3. 최고 점수로 리더보드 1등에 도전!

### 점수표
| 영역 | 점수 |
|------|------|
| 🎯 Bullseye | 50점 |
| Bull | 25점 |
| Triple 20 | 60점 (최고!) |
| Double | 기본 x 2 |

### 보너스 라운드 🔥
**180점** 또는 **Bullseye 3번** 달성 시 남은 시간 동안 무제한 다트!

## Features

- ✅ 실시간 리더보드 (Firebase)
- ✅ 튜토리얼 (첫 플레이어용)
- ✅ 보너스 라운드
- ✅ 어뷰저 탐지 + Wall of Shame
- ✅ 반응형 (모바일 최적화)
- ✅ High DPI 지원 (Retina)

## Tech Stack

- HTML5 Canvas + Vanilla JS
- Firebase Firestore
- GitHub Pages
